## 1. 테스트 계획

### 테스트 시나리오

- **시나리오 1: 최초 관리자 설정 및 직원 가입/승인**
  - **Given**: 시스템에 관리자가 존재하지 않는다.
  - **When**: 사용자가 `/admin/setup`에서 관리자 계정 정보를 입력하고 생성한다.
  - **Then**: `is_admin=true`인 관리자 계정이 생성되고, 이후 `/admin/setup` 접근이 차단된다.
  - **When**: 신규 직원이 `/signup`에서 이름, 4자리 PIN, 시급을 입력하고 가입한다.
  - **Then**: `status='pending'` 상태로 가입되며, 관리자 페이지에서 승인 대기 목록에 노출된다.
  - **When**: 관리자가 해당 직원의 상태를 `active`(재직)로 변경한다.
  - **Then**: 해당 직원이 PIN 번호로 정상 로그인 및 출퇴근 등록이 가능해진다.

- **시나리오 2: 출퇴근 등록 및 급여 계산**
  - **Given**: `active` 상태인 직원이 로그인한 상태이다.
  - **When**: 출근 버튼을 누르고, 이후 퇴근 버튼을 누른다.
  - **Then**: `attendance` 테이블에 해당 일자의 `clock_in`과 `clock_out`이 기록되며, 마이페이지에서 총 근무 시간과 `시급 × 근무시간`으로 산정된 예상 급여가 계산되어 표시된다.
