## 1. 테스트 계획

### 테스트 시나리오

- **시나리오 1: 플라워샵 등록, 허브 진입, 관리자 설정 및 직원 가입/승인**
  - **Given**: 시스템에 플라워샵이 존재하지 않는다.
  - **When**: 사용자가 `/shop/register`에서 플라워샵을 등록하고 메인 화면(`/`)에서 해당 플라워샵을 선택한다.
  - **Then**: `/shop/[id]` (허브 화면)으로 이동하며, 관리자 및 직원 등록/로그인 버튼이 노출된다.
  - **When**: 허브 화면에서 관리자 등록 화면(`/admin/setup`)으로 진입해 관리자를 생성한다.
  - **Then**: 해당 플라워샵의 `staff` 테이블에 `is_admin=true`인 관리자 계정이 정상 생성된다.
  - **When**: 직원이 회원가입을 신청하고 관리자가 승인한다.
  - **Then**: `status='active'`로 변경되어 출퇴근 기록이 가능하다.
