## 1. 테스트 계획

### 테스트 시나리오 (수용 기준)
- **시나리오 1: 직원 로그인 및 출퇴근 등록**
  - **Given**: 직원이 가입되어 있다.
  - **When**: `/`에서 이름을 선택하고 4자리 PIN을 입력 후 로그인하여 출근/퇴근 시간을 입력한다.
  - **Then**: `/employee/dashboard`에 정상적으로 기록이 반영되고 급여가 계산된다.
- **시나리오 2: 관리자 급여 확인**
  - **Given**: 관리자 계정으로 로그인했다.
  - **When**: `/admin` 페이지를 연다.
  - **Then**: 등록된 모든 직원의 월별 근무 시간 합계와 급여 총액이 정확히 계산되어 표시된다.

## 2. 배포와 운영

### 배포 프로세스
1. GitHub 레파지토리에 코드 푸시
