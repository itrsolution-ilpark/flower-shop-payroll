## 1. 프로젝트 개요 (한눈에 보기)

### 프로젝트 목적
여러 개의 플라워샵을 각각 독립적으로 관리하며, 각 플라워샵 소속 직원들의 일일 출퇴근 기록을 바탕으로 근무 시간을 산정하고 시급을 적용하여 월별 급여를 자동으로 계산 및 관리하는 멀티 테넌트 웹 프로그램입니다.

### 핵심 가치
- **플라워샵별 독립 관리**: 메인 화면에서 플라워샵 검색 및 등록, 선택 후 해당 샵 소속의 관리자와 직원들을 분리하여 관리
- **통합 직원/관리자 구조**: 관리자 역시 `staff` 테이블에서 `is_admin=true` 속성으로 관리되어 데이터 정합성 확보
- **직원 생애주기 관리**: 직원이 가입 신청 후 관리자의 '승인'을 거쳐야 '재직(입사)' 상태가 되며, 퇴사 처리된 직원은 로그인 및 출퇴근 등록 제한
- **안전한 기록 및 인증**: 4자리 PIN 번호 등록/수정 시 2회 입력 검증(Validation) 및 PIN 인증을 통한 본인 출퇴근 기록 조회

### 주요 용어 정의
- **플라워샵 (Shop)**: 독립된 근무지 단위
- **시급**: 시간당 임금 (원 단위, 정수)
- **근무 상태**: `pending`(승인 대기), `active`(재직/입사), `resigned`(퇴사)
- **관리자**: 특정 플라워샵에 속하며 `is_admin=true` 속성을 가진 계정

## 2. 사용자와 사용 시나리오

### 사용자 역할

| 역할 | 설명 | 주요 권한 |
| --- | --- | --- |
| **비회원/신규직원** | 특정 플라워샵에 새로 온 직원 | - 메인 화면에서 플라워샵 검색 및 선택 후 허브 화면을 거쳐 직원 회원가입 신청 (이름, 4자리 PIN 2회 입력, 희망 시급 입력, 상태=`pending`) |
| **직원 (재직자)** | 관리자 승인을 받은 직원 (`status='active'`) | - 플라워샵 허브 화면에서 관리자 등록 여부 확인 후 직원 로그인 선택<br>- 4자리 PIN으로 로그인하여 일별 출근/퇴근 시간 등록 및 본인 근무 내역 조회 |
| **관리자** | 특정 플라워샵의 대표 또는 점장 (`is_admin=true`) | - 메인 화면에서 플라워샵 검색 및 선택 후 진입한 허브 화면에서 관리자 미등록 시 '관리자 등록' 버튼 노출<br>- 소속 플라워샵의 신규 가입 직원 승인 및 상태 변경 (`active`/`resigned`)<br>- 직원별 시급 설정 및 출퇴근 기록 수정<br>- 월별/직원별 급여 집계 확인 |

### 사용자 시나리오
1. **플라워샵 등록 및 검색**: 메인 화면에서 플라워샵을 신규 등록(`/shop/register`)하거나 검색창에 플라워샵 이름을 입력하여 필터링된 목록에서 선택합니다.
2. **플라워샵 선택 및 허브 진입**: 메인 화면에서 플라워샵을 선택하면, 해당 샵의 관리자 등록 상태를 판별하는 허브 화면(`/shop/[id]`)으로 진입합니다.
3. **관리자 등록/로그인 및 직원 가입/승인**: 허브 화면에서 관리자가 미등록된 경우 '관리자 등록' 버튼만 노출되며, 등록 완료 시 '직원 로그인' 및 '직원 가입' 버튼이 활성화됩니다.
4. **출퇴근 등록 및 급여 정산**: 승인된 직원이 로그인하여 출퇴근을 기록하고, 관리자는 월말에 급여 집계표를 확인합니다.

| F-01-2 | 직원 승인 관리 | 관리자가 가입 대기중인 직원의 상태를 승인(재직) 또는 퇴사 처리 | 관리자 | **Given** 관리자 권한으로 대시보드에 접속했다.<br>**When** 대기 중인 직원의 승인 버튼을 누른다.<br>**Then** `status='active'`로 변경되어 출퇴근이 가능해진다. |
