## 1. 프로젝트 개요 (한눈에 보기)

### 프로젝트 목적
여러 개의 화원(플라워샵)을 각각 독립적으로 관리하며, 각 화원 소속 직원들의 일일 출퇴근 기록을 바탕으로 근무 시간을 산정하고 시급을 적용하여 월별 급여를 자동으로 계산 및 관리하는 멀티 테넌트 웹 프로그램입니다.

### 핵심 가치
- **화원별 독립 관리**: 화원(매장) 등록 후 해당 화원 소속의 관리자와 직원들을 분리하여 관리
- **화원별 관리자 설정**: 시스템 최초 접속 또는 화원 등록 시 해당 화원의 관리자 계정 생성 기능 제공
- **직원 생애주기 관리**: 직원이 가입 신청 후 관리자의 '승인'을 거쳐야 '재직(입사)' 상태가 되며, 퇴사 처리된 직원은 로그인 및 출퇴근 등록 제한
- **안전한 기록 및 인증**: 4자리 PIN 번호 등록/수정 시 2회 입력 검증(Validation) 및 PIN 인증을 통한 본인 출퇴근 기록 조회

### 주요 용어 정의
- **화원 (Shop)**: 독립된 근무지 단위
- **시급**: 시간당 임금 (원 단위, 정수)
- **근무 상태**: `pending`(승인 대기), `active`(재직/입사), `resigned`(퇴사)
- **관리자**: 특정 화원에 속하며 `is_admin=true` 속성을 가진 계정

## 2. 사용자와 사용 시나리오

### 사용자 역할

| 역할 | 설명 | 주요 권한 |
| --- | --- | --- |
| **비회원/신규직원** | 특정 화원에 새로 온 직원 | - 화원 선택 후 직원 회원가입 신청 (이름, 4자리 PIN 2회 입력, 희망 시급 입력, 상태=`pending`) |
| **직원 (재직자)** | 관리자 승인을 받은 직원 (`status='active'`) | - 화원 선택 및 4자리 PIN으로 로그인<br>- 일별 출근/퇴근 시간 등록 및 본인 근무 내역 조회 |
| **관리자** | 특정 화원의 대표 또는 점장 (`is_admin=true`) | - 화원 등록 및 관리자 계정 생성 (`/admin/setup`)<br>- 소속 화원의 신규 가입 직원 승인 및 상태 변경 (`active`/`resigned`)<br>- 직원별 시급 설정 및 출퇴근 기록 수정<br>- 월별/직원별 급여 집계 확인 |

### 사용자 시나리오
1. **화원 및 관리자 등록**: 메인 화면에서 화원을 신규 등록하거나, 이미 등록된 화원의 관리자 로그인 페이지로 진입하여 관리자 계정을 설정합니다.
2. **직원 가입 및 승인**: 직원이 해당 화원을 선택하고 회원가입을 신청하면 대기 상태(`pending`)가 되고, 해당 화원 관리자가 승인(`active`)합니다.
3. **출퇴근 등록 및 급여 정산**: 승인된 직원이 로그인하여 출퇴근을 기록하고, 관리자는 월말에 급여 집계표를 확인합니다.

## 3. 기능 명세

### 기능 목록

| 기능 ID | 기능명 | 설명 | 대상 사용자 | 수용 기준 (Given/When/Then) |
| --- | --- | --- | --- | --- |
| F-00-1 | 화원 등록 | 시스템에 새로운 화원(플라워샵)을 등록 | 관리자/점주 | **Given** 새로운 화원을 등록하고자 한다.<br>**When** 화원 이름과 기본 정보를 입력하고 등록한다.<br>**Then** 새로운 화원 레코드가 생성된다. |
| F-00-2 | 화원별 관리자 설정 및 오류 방지 | 특정 화원의 관리자 계정 생성 (이미 관리자가 존재할 경우 오류 처리) | 관리자 | **Given** 화원이 선택되어 있다.<br>**When** 관리자 정보와 4자리 PIN(2회 입력)을 입력한다.<br>**Then** 이미 해당 화원에 관리자가 존재하면 "이미 관리자가 등록된 화원입니다" 에러를 노출하고 중복 등록을 방지한다. |
| F-01 | 직원 회원가입 (Validation 포함) | 화원 선택 후 이름, 4자리 PIN(2회 입력), 시급 입력 및 가입 신청 | 신규 직원 | **Given** 특정 화원이 선택되어 있다.<br>**When** PIN 번호 2개가 일치하도록 입력하고 가입한다.<br>**Then** `status='pending'` 상태로 가입된다. |
| F-01-2 | 직원 승인 관리 | 관리자가 가입 대기중인 직원의 상태를 승인(재직) 또는 퇴사 처리 | 관리자 | **Given** 관리자 권한이다.<br>**When** 대기 중인 직원의 승인 버튼을 누른다.<br>**Then** `status='active'`로 변경되어 출퇴근이 가능해진다. |
| F-02 | 출퇴근 기록 관리 | 재직(`active`) 상태인 직원의 일별 출근/퇴근 시간 등록 | 직원 | **Given** 승인된 재직 직원이다.<br>**When** 출퇴근 시간을 입력하고 저장한다.<br>**Then** 기록이 저장된다. |
| F-03 | 본인 근무 조회 | 본인의 월별 출퇴근 기록 및 예상 급여 조회 | 직원 | **Given** 로그인된 직원이다.<br>**When** 마이페이지에 접속한다.<br>**Then** 총 근무 시간과 예상 급여가 표시된다. |
| F-04 | 관리자 대시보드 | 소속 화원의 직원별 월별 급여 집계표 확인 및 직원 상태 관리 | 관리자 | **Given** 관리자 계정으로 로그인했다.<br>**When** `/admin`에 접속한다.<br>**Then** 해당 화원의 직원별 근무 시간과 급여 총액 및 재직 상태를 관리할 수 있다. |
