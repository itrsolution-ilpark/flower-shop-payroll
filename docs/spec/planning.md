## 1. 프로젝트 개요 (한눈에 보기)

### 프로젝트 목적
화원(플라워샵) 직원들의 일일 출퇴근 기록을 바탕으로 근무 시간을 산정하고, 시급을 적용하여 월별 급여를 자동으로 계산 및 관리하는 웹 프로그램입니다.

### 핵심 가치
- **관리자 최초 설정**: 시스템 최초 접속 시 관리자 계정 생성 기능 제공
- **직원 생애주기 관리**: 직원이 가입 신청 후 관리자의 '승인'을 거쳐야 '재직(입사)' 상태가 되며, 퇴사 처리된 직원은 로그인 및 출퇴근 등록 제한
- **안전한 기록 관리**: 4자리 PIN 번호 인증을 통한 본인 출퇴근 기록 조회 및 등록, 관리자의 수정/보완 권한

### 주요 용어 정의
- **시급**: 시간당 임금 (원 단위, 정수)
- **근무 상태**: `pending`(승인 대기), `active`(재직/입사), `resigned`(퇴사)
- **관리자**: `is_admin=true` 속성을 가진 계정으로, 직원 승인, 시급 설정 및 전체 데이터 보정 권한 보유

## 2. 사용자와 사용 시나리오

### 사용자 역할

| 역할 | 설명 | 주요 권한 |
| --- | --- | --- |
| **비회원/신규직원** | 화원에 새로 온 직원 | - 직원 회원가입 신청 (이름, 4자리 PIN, 시급 입력, 상태=`pending`) |
| **직원 (재직자)** | 관리자 승인을 받은 직원 (`status='active'`) | - 4자리 PIN으로 로그인<br>- 일별 출근/퇴근 시간 등록 및 본인 근무 내역 조회 |
| **관리자** | 화원 대표 또는 점장 (`is_admin=true`) | - 최초 시스템 설정 시 관리자 계정 생성 (`/admin/setup`)<br>- 신규 가입 직원 승인 및 상태 변경 (`active`/`resigned`)<br>- 직원별 시급 설정 및 출퇴근 기록 수정<br>- 월별/직원별 급여 집계 확인 |

### 사용자 시나리오
1. **최초 관리자 생성**: 사이트에 처음 접속하여 `/admin/setup`을 통해 관리자 계정을 생성합니다.
2. **직원 가입 및 승인**: 신규 직원이 회원가입을 하면 대기 상태(`pending`)가 되고, 관리자가 관리자 대시보드에서 이를 확인 후 승인(`active`)합니다.
3. **출퇴근 등록 및 급여 정산**: 승인된 직원이 로그인하여 출퇴근을 기록하고, 관리자는 월말에 급여 집계표를 확인합니다.

## 3. 기능 명세

### 기능 목록

| 기능 ID | 기능명 | 설명 | 대상 사용자 | 수용 기준 (Given/When/Then) |
| --- | --- | --- | --- | --- |
| F-00 | 최초 관리자 설정 | 시스템에 관리자가 없을 경우 최초 1회 관리자 계정 생성 | 관리자 | **Given** 시스템에 관리자가 없다.<br>**When** `/admin/setup`에서 관리자 정보를 입력한다.<br> **Then** `is_admin=true`인 관리자 계정이 생성된다. |
| F-01 | 직원 회원가입 | 이름, 4자리 PIN, 희망 시급 입력 및 가입 신청 | 신규 직원 | **Given** 미등록 직원이다.<br>**When** 정보를 입력하고 가입한다.<br>**Then** `status='pending'`(대기) 상태로 가입된다. |
| F-01-2 | 직원 승인 관리 | 관리자가 가입 대기중인 직원의 상태를 승인(재직) 또는 퇴사 처리 | 관리자 | **Given** 관리자 권한이다.<br>**When** 대기 중인 직원의 승인 버튼을 누른다.<br>**Then** `status='active'`로 변경되어 출퇴근이 가능해진다. |
| F-02 | 출퇴근 기록 관리 | 재직(`active`) 상태인 직원의 일별 출근/퇴근 시간 등록 | 직원 | **Given** 승인된 재직 직원이다.<br>**When** 출퇴근 시간을 입력하고 저장한다.<br>**Then** 기록이 저장된다. |
| F-03 | 본인 근무 조회 | 본인의 월별 출퇴근 기록 및 예상 급여 조회 | 직원 | **Given** 로그인된 직원이다.<br>**When** 마이페이지에 접속한다.<br>**Then** 총 근무 시간과 예상 급여가 표시된다. |
| F-04 | 관리자 대시보드 | 전체 직원 월별 급여 집계표 확인 및 직원 상태 관리 | 관리자 | **Given** 관리자 계정으로 로그인했다.<br>**When** `/admin`에 접속한다.<br>**Then** 직원별 근무 시간과 급여 총액 및 재직 상태를 관리할 수 있다. |
