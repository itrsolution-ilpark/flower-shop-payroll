## 1. 화면과 주소(URL) 구성

### 전체 화면 목록 및 레이아웃 상세

모든 화면은 상단부터 차례대로 정돈된 여백과 카드 UI로 배치되며, 버튼명 표기에는 대괄호(`[]`)를 사용하지 않고 직관적인 텍스트 레이블을 적용합니다.

| URL 경로 | 화면명 | 핵심 UI 구성요소 및 상단 우선 배치 레이아웃 |
| --- | --- | --- |
| `/system-setup` | 시스템 관리자 최초 등록 | 1. 상단 바: 시스템 마스터 설정 안내 배너<br>2. 본문 카드: 관리자 이름 입력창, 4자리 PIN 입력창, 4자리 PIN 확인 입력창<br>3. 하단 액션: 시스템 관리자 생성 및 시작 버튼 |
| `/` | 전체 플라워샵 메인 | 1. 상단 헤더: "플라워샵 근무 관리" 로고 및 시스템 관리자 플라워샵 등록/수정 버튼 (PIN 모달 연동)<br>2. 검색 영역: 상단 배치 실시간 검색 인풋 (`placeholder="플라워샵 이름을 검색하세요..."`)<br>3. 매장 목록 그리드: 매장명, 재직 직원 수, 플라워샵 메인 바로가기 버튼 |
| `/shop/register` | 플라워샵 등록 및 관리 | 1. 상단 헤더: 플라워샵 등록 및 관리 뒤로가기 네비게이션<br>2. 신규 등록 카드: 신규 플라워샵명 입력 인풋, 플라워샵 추가 버튼<br>3. 등록 매장 목록 카드: 매장명 수정 인라인 인풋 및 수정 내용 저장 버튼 |
| `/shop/[id]` | 플라워샵 메인 | 1. 상단 헤더: 플라워샵명 타이틀 및 전체 플라워샵 메인으로 이동 링크<br>2. 관리자 미등록 시: 안내 알림 ("등록된 관리자가 없습니다") 및 관리자 등록 버튼<br>3. 관리자 등록 완료 시:<br>   - 상단: 관리자 로그인 버튼 (PIN 인증 후 `/admin` 이동)<br>   - 중앙: 직원 로그인 영역 (재직 직원 선택 드롭다운, 4자리 PIN 입력, 근무 관리 시작 버튼)<br>   - 하단: 신규 직원 가입 신청 버튼 |
| `/admin/setup` | 플라워샵별 관리자 등록 | 1. 상단 헤더: 플라워샵별 관리자 등록 화면 타이틀<br>2. 고정 안내: 소속 플라워샵명 고정 뱃지<br>3. 등록/수정 폼: 관리자 이름 인풋, 4자리 PIN 인풋, 4자리 PIN 확인 인풋<br>4. 액션 버튼: 관리자 정보 저장 완료 버튼 |
| `/admin` | 플라워샵 관리 대시보드 | 1. 상단 헤더: 매장명 및 네비게이션 (근무 기록/급여 정산 화면 이동 링크)<br>2. 상태별 탭/섹션 상단 배치:<br>   - 승인 대기자 목록: 이름, 신청일, 시급 설정 인풋, 승인 완료 버튼<br>   - 재직 직원 목록: 이름, 시급 수정 인풋, 시급 저장 버튼, 퇴사 처리 버튼<br>   - 퇴사자 목록: 이름, 퇴사일, 조회 전용 표시 |
| `/admin/attendance` | 근무 기록 및 급여 정산 | 1. 상단 툴바: 정산 연월 선택 셀렉트박스 (예: 2025년 05월) 및 엑셀형 요약 다운로드<br>2. 직원별 정산 테이블:<br>   - 열 구성: 직원명, 상태 뱃지(승인대기/재직/퇴사), 총 근무 시간, 시급, 총 지급 급여, 상세/수정 액션<br>3. 일자별 근무 기록 수정 모달: 날짜 선택, 출근 시간 피커, 퇴근 시간 피커, 기록 보완 저장 버튼 |
| `/signup` | 직원 가입 신청 | 1. 상단 헤더: 매장명 표시 및 가입 신청 타이틀<br>2. 입력 폼: 직원 이름, 4자리 PIN, 4자리 PIN 확인<br>3. 액션 버튼: 가입 신청 완료 버튼 (완료 시 안내 알림 후 플라워샵 메인으로 복귀) |
| `/employee/dashboard` | 직원 근무 관리 (마이페이지) | 1. 상단 헤더: 직원 이름, 매장명, 책정 시급 안내 태그, PIN 번호 변경 버튼, 로그아웃 버튼<br>2. 출퇴근 등록/수정 상단 카드 (세련된 타임피커):<br>   - 날짜 선택기 (Date Picker, 기본값 오늘)<br>   - 세련된 휠/타임피커: 출근 시간 선택 인풋, 퇴근 시간 선택 인풋<br>   - 출근 기록 버튼, 퇴근 기록 버튼, 선택 시간으로 저장 버튼<br>3. 이번 달 근무 요약 카드: 총 근무 시간 (00시간 00분), 총 예상 급여 (원 단위 서식)<br>4. 근무 이력 테이블: 날짜, 출근 시간, 퇴근 시간, 근무 분, 수정 버튼 |

## 2. 디자인 가이드

### 세련된 모던 디자인 시스템 가이드

1. **레이아웃 및 공간 배치 원칙**:
   - 모든 페이지는 불필요한 공백 없이 화면 상단(`pt-6` / `pt-8`)부터 시선이 머무는 주요 정보와 인풋을 직관적으로 우선 배치합니다.
   - 세련된 모바일/데스크톱 반응형 컨테이너: 기본 `max-w-xl mx-auto px-4` 중심의 정돈된 카드 뷰.

2. **색상 팔레트 (Color Palette)**:
   - **Primary (메인 포인트)**: `#059669` (세련된 에메랄드 그린 - 플라워샵 아이덴티티) / 호버 `#047857`
   - **Secondary (관리자/강조)**: `#1E293B` (슬레이트 딥 다크 네이비)
   - **배경 (Background)**: `#F8FAFC` (화사하고 깨끗한 오프화이트)
   - **카드 및 모달 (Surface)**: `#FFFFFF` (입체감을 주는 부드러운 박스 섀도우 `shadow-sm hover:shadow-md`)
   - **텍스트**: 본문 `#0F172A` (Slate 900), 서브 텍스트 `#64748B` (Slate 500)
   - **테두리선 (Border)**: `#E2E8F0` (은은한 라이트 그레이)

3. **상태 뱃지 (Status Badge) 스타일**:
   - **승인대기 (`pending`)**: 배경 `#FEF3C7`, 글자 `#D97706` (따뜻한 앰버 옐로우)
   - **재직 (`active`)**: 배경 `#ECFDF5`, 글자 `#059669` (산뜻한 그린)
   - **퇴사 (`resigned`)**: 배경 `#F1F5F9`, 글자 `#64748B` (차분한 그레이)

4. **시간 선택 피커 (Time Picker) 사양**:
   - 기본 브라우저 둔탁한 타임 인풋 대신, 시(00~23)와 분(00~55, 5분 단위 스텝)을 직관적으로 클릭/스크롤할 수 있는 세련된 팝오버 휠 또는 세그먼트 버튼 셀렉터 컴포넌트 제공.

5. **버튼 및 인터랙션**:
   - 대괄호 표기 일체 배제, 모바일 터치에 최적화된 최소 높이 46px, 둥근 모서리 `rounded-xl`, 부드러운 전환 효과 `transition-all duration-200 active:scale-95`.
