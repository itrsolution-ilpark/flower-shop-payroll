## 1. 화면과 주소(URL) 구성

### 화면 구성

| URL 경로 | 화면명 | 주요 UI 요소 |
| --- | --- | --- |
| `/` | 메인 / 화원 선택 화면 | 등록된 화원 목록 드롭다운, 해당 화원 소속 직원 및 관리자(`is_admin=true` 포함) 로그인 목록, 화원 등록 버튼 |
| `/shop/register` | 화원 등록 화면 | 화원명 등 정보 입력 및 등록 완료 버튼 |
| `/signup` | 직원 회원가입 화면 | 화원 선택, 이름 입력, 4자리 PIN 입력 및 확인용 PIN 재입력, 시급 입력, 가입 신청 버튼 (불일치 시 에러 메시지 노출) |
| `/admin/setup` | 화원별 관리자 등록 화면 (타이틀: '화원별 관리자 등록 화면') | 초기 화면에서 선택한 화원이 고정되어 수정 불가 표시, 관리자 미등록 시 신규 등록 모드(PIN 2회 입력), 기등록 시 관리자 내역 표시 및 수정 모드 |
| `/employee/dashboard` | 직원 마이페이지 | 출근/퇴근 시간 입력, 근무 내역 리스트, 예상 급여 텍스트 |
| `/admin` | 관리자 대시보드 | 화원별 직원 월별 급여 요약 표, 직원 상태(승인/대기/퇴사) 변경 관리 탭 |
| `/admin/attendance` | 관리자 근무 기록 관리 | 직원별 출근/퇴근 시간 수정/삭제 모달 포함 테이블 |

### 디자인 시스템 색상 (Hex)
- 주 색상(Primary): `#2E7D32` (포레스트 그린)
- 보조 색상(Secondary): `#81C784` (연두색)
- 배경 색상(Background): `#F1F8E9` (연한 초록빛)
- 텍스트 색상: `#212121` (진한 회색)
- 에러 색상: `#D32F2F` (빨강)

## 2. 디자인 가이드

### 디자인 가이드
- **폰트**: Pretendard (산세리프)
- **버튼 스타일**: 모바일 터치 친화적으로 높이 48px 이상, 둥근 모서리(`rounded-lg`)
- **반응형 디자인**: 모바일 웹 최우선 세로형 레이아웃 (`max-w-md mx-auto` 컨테이너 구조)
