## 1. 화면과 주소(URL) 구성

### 공통 화면 규칙
- 모든 경로의 최상단에 세련된 ‘플라워샵 근무 관리’ 프로그램 배너를 표시합니다.
- 사용자가 보는 비밀 입력 라벨은 ‘비밀’, 확인 라벨은 ‘비밀 확인’으로 표시합니다. 입력은 숫자만 허용하고 최대 길이는 4자입니다. 화면의 오류·안내 문구는 한글로 표시합니다.
- 로그인 여부와 관계없이 페이지 틀은 표시합니다. 인증이 필요한 기능을 누르면 로그인 안내를 표시합니다. 잘못된 `shop_id`나 없는 플라워샵에는 ‘플라워샵을 찾을 수 없습니다.’를 표시합니다.

### 화면별 구성

| URL | 화면 및 상단부터의 구성 |
| --- | --- |
| `/` | 공통 배너 → 상단 배너 바로 아래 ‘플라워샵 관리’ 버튼 → 검색 입력(`플라워샵 이름을 검색하세요...`) → 별도 영역으로 지정된 ‘등록된 플라워샵’ 목록 카드 → 플라워샵 이름, 재직 직원 수, ‘선택’ 버튼. 결과가 없으면 ‘검색 결과가 없습니다.’ |
| `/system-setup` | 공통 배너 → ‘시스템 관리자 등록 및 로그인’ 카드 → 이름 → ‘비밀’ → 최초 등록일 때만 ‘비밀 확인’ → ‘시스템 관리자 생성’ 또는 ‘로그인’ 버튼 |
| `/shop/register` | 공통 배너 → ‘플라워샵 등록 및 관리’ 카드 → 메인으로 돌아가기 → 새 플라워샵 이름 입력과 ‘플라워샵 추가’ 버튼 → 등록된 플라워샵 목록과 각 항목의 이름 수정 입력 및 ‘수정 내용 저장’ 버튼 |
| `/shop/[id]` | 공통 배너 → 플라워샵 이름 및 메인으로 돌아가기 → 관리자가 없으면 ‘등록된 관리자가 없습니다’와 ‘관리자 등록’ 버튼 → 관리자가 있으면 ‘관리자 로그인’(로그인 화면 내 관리자 본인 정보 수정 기능 포함), ‘직원 로그인’(대표 제외된 재직 직원만 표시), ‘직원 가입 신청’ 기능 |
| `/admin/setup?shop_id=[id]` | 공통 배너 → ‘플라워샵별 관리자 등록’ 카드 → 수정 불가한 플라워샵 이름 표시 → 관리자 이름, ‘비밀’, ‘비밀 확인’ → ‘관리자 정보 저장’. 관리자가 없으면 등록 모드, 있으면 인증 후 수정 모드 |
| `/signup?shop_id=[id]` | 공통 배너 → 플라워샵 이름 → ‘직원 가입 신청’ 카드 → 직원 이름, ‘비밀’, ‘비밀 확인’ → ‘가입 신청 완료’ 버튼 |
| `/admin` | 공통 배너 → 플라워샵 이름 및 ‘직원 관리’ 제목 → 승인 대기·재직·퇴사 목록 → 대기 직원의 시급/월급 선택, 금액, 적용 시작일, 승인 버튼 → 재직 직원의 상태·급여 조건 수정 및 퇴사 처리 |
| `/admin/attendance` | 공통 배너 → ‘근무 기록 및 급여 정산’ 카드 → 월 선택(`YYYY-MM`) → 직원별 이름, 상태, 급여 유형, 총 근무 시간, 지급 예정액 → 직원 선택 시 하단 상세 (시급 직원은 날짜·출근·퇴근·근무 분 수정, 월급 직원은 출근·퇴근 항목 제외) |
| `/employee/dashboard` | 공통 배너 → 직원·플라워샵 이름과 적용 급여 조건 → ‘비밀번호 변경’, ‘로그아웃’ → 월 선택(`YYYY-MM`) → 시급 직원에게만 날짜·출근·퇴근 선택과 저장 기능 및 예상 급여 조회 |

### 시간·월 선택 동작
- 날짜 입력 형식은 `YYYY-MM-DD`, 시간 입력 형식은 24시간제 `HH:mm`, 월 선택은 `YYYY-MM`입니다.
- 직원 근무 화면의 최초 월은 현재 월, 최초 근무 날짜는 오늘입니다.
- 출근 또는 퇴근 시각이 비어 있거나 퇴근이 출근보다 빠르거나 같으면 저장을 거부합니다.

## 2. 디자인 가이드

### 디자인 가이드

#### 공통 레이아웃 및 배너
- 모든 경로의 화면 최상단에 공통 프로그램 배너를 배치하여 일관성을 높이고 전체적인 화면을 세련되게 구성합니다.
- 배너에는 정확히 ‘플라워샵 근무 관리’ 문구를 사용합니다.
- 배너 높이는 데스크톱 64px, 모바일 56px로 하고, 배경은 `#FFFFFF`, 아래쪽 테두리는 `#E2E8F0` 1px로 처리합니다. 제목 글자색은 `#0F172A`, 굵기는 700으로 합니다.
- 본문 영역은 최대 너비 `1120px` 컨테이너에 배치하며, 전체 화면 배경은 `#F8FAFC`, 카드 배경은 `#FFFFFF`, 카드 테두리는 `#E2E8F0` 1px, 모서리는 16px로 통일합니다.

#### 메인 화면 레이아웃
- 메인 화면에서 ‘플라워샵 관리’ 버튼은 공통 배너 바로 아래에 배치합니다.
- ‘등록된 플라워샵’은 명확하게 시각적으로 구분된 별도 카드 영역으로 구성합니다.
- 플라워샵 목록 안의 이동 버튼 문구는 ‘선택’으로 고정하여 표시합니다.

#### 색상 팔레트
| 용도 | 색상 |
| --- | --- |
| 주요 버튼 및 강조 | `#059669` (Emerald 600) |
| 주요 버튼 호버 | `#047857` (Emerald 700) |
| 보조 강조 | `#1E293B` (Slate 800) |
| 화면 배경 | `#F8FAFC` (Slate 50) |
| 카드 배경 | `#FFFFFF` |
| 기본 글자 | `#0F172A` (Slate 900) |
| 보조 글자 | `#64748B` (Slate 500) |
| 테두리 | `#E2E8F0` (Slate 200) |

#### 입력란과 버튼
- 버튼 높이는 최소 46px, 모서리 둥글기는 12px로 설정하고 `transition-all duration-200` 효과를 적용합니다.
- PIN 관련 문구는 모두 ‘비밀’ 및 ‘비밀 확인’으로 표기합니다.
