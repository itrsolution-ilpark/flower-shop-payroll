## 1. 화면과 주소(URL) 구성

### 전체 화면 흐름도
`메인 화면 (/)` → `로그인 화면 (/login)` 또는 `직원/관리자 가입 신청 (/signup)` → 권한별 대시보드 (`/system/dashboard`, `/shop-admin/dashboard`, `/employee/dashboard`)

### URL별 화면 구성

| URL | 주요 화면 구성 및 컴포넌트 배치 |
| --- | --- |
| `/` (메인 화면) | • 상단: 공통 배너 ('플라워샵 근무 관리')<br>• 중앙: 플라워샵 홍보 배너 및 시스템 소개 문구, 주요 동작 버튼 ('로그인 바로가기', '직원/관리자 등록 신청')<br>• 하단: 눈에 띄는 시스템 관리자 전용 링크 ('시스템 관리자 접속') |
| `/system/login` | • 상단 배너<br>• '시스템 관리자 로그인' 카드: 이름 입력창, 6자리 비밀번호 입력창, '로그인' 버튼<br>• 등록된 관리자가 0명일 경우 자동으로 최초 등록 화면 링크 표시 |
| `/system/setup` | • 상단 배너<br>• '시스템 관리자 최초 등록' 카드: 이름, 6자리 비밀번호, 6자리 비밀번호 확인, '관리자 생성' 버튼 (시스템 관리자가 이미 존재하면 접근 차단) |
| `/system/dashboard` | • 상단 배너 및 로그아웃 버튼<br>• 탭 1: '플라워샵 등록/관리' - 신규 플라워샵 등록 폼, 플라워샵 목록(이름 수정 인풋, 활성/비활성 토글 스위치, 소속 관리자/직원 수 표시)<br>• 탭 2: '시스템 관리자 관리' - 추가 시스템 관리자 등록(이름, 6자리 비밀번호) 및 관리자 목록 조회 |
| `/login` (통합 로그인) | • 상단 배너<br>• 로그인 대상 플라워샵 선택 드롭다운(활성화된 샵만 노출)<br>• 사용자 구분 탭 ('플라워샵 관리자' [6자리] / '직원' [4자리])<br>• 이름 입력창, 비밀번호 입력창, '로그인' 버튼<br>• 하단 링크: '플라워샵 직원 가입 신청' 및 '플라워샵 최초 관리자 개설' |
| `/signup` (가입 신청) | • 상단 배너<br>• 신청 유형 선택 탭: '직원 가입 신청' / '플라워샵 최초 관리자 개설'<br>• 플라워샵 선택 드롭다운<br>• 이름, 비밀번호(직원 4자리, 관리자 6자리), 비밀번호 확인<br>• 플라워샵에 관리자가 없으면 직원 가입 탭은 비활성화되고 '관리자 개설 필요' 안내 표기 |
| `/shop-admin/dashboard` | • 상단 배너, 플라워샵 이름 표시, 관리자 정보 수정 버튼, 로그아웃 버튼<br>• **직원 관리 탭**: 승인 대기자 목록(급여형태[시급/월급], 계산단위[분/시간], 시급/월급액, 적용일 입력 후 '승인' 버튼), 승인된 재직 직원 목록(조건 수정, '퇴사 처리' 버튼)<br>• **추가 관리자 등록 탭**: 소속 플라워샵의 추가 관리자 등록 폼(이름, 6자리 비밀번호)<br>• **근무 및 급여 정산 탭**: 월 선택기(`YYYY-MM`), 직원별 총 근무시간 및 지급액 표, 직원 선택 시 일별 출퇴근 기록 인라인 수정 폼, **'CSV 다운로드'** 버튼 |
| `/employee/dashboard` | • 상단 배너, 직원 이름 및 소속 플라워샵 표기, '비밀번호 변경', 로그아웃 버튼<br>• 내 급여 조건 카드: 시급/월급 여부, 적용 금액, 계산 단위(시간/분)<br>• 일별 출퇴근 등록 카드: 날짜 선택(기본 오늘), 출근 시간 선택, 퇴근 시간 선택, '출퇴근 기록 저장' 버튼 (월급 직원은 비활성화 또는 안내 문구 표기)<br>• 월별 근무 및 급여 조회 카드: 월 선택기(`YYYY-MM`), 일별 출퇴근 내역 테이블, 예상 월 급여 총액 계산 결과 |

## 2. 디자인 가이드

### 디자인 시스템 및 스타일 가이드

#### 공통 헤더 배너
- 모든 화면 상단에 너비 100%, 높이 64px의 고정 배너를 표시합니다.
- 텍스트: **‘플라워샵 근무 관리’** (Font-weight: 700, 색상: `#0F172A`, 크기: 20px)
- 배경색: `#FFFFFF`, 하단 테두리: `#E2E8F0` 1px Solid

#### 색상 팔레트
| 용도 | Tailwind 클래스 | Hex 코드 | 설명 |
| --- | --- | --- | --- |
| Primary (주조색) | `bg-emerald-600` / `hover:bg-emerald-700` | `#059669` / `#047857` | 주요 액션 버튼(승인, 등록, 저장) |
| Secondary (보조) | `bg-slate-800` / `hover:bg-slate-900` | `#1E293B` / `#0F172A` | 시스템 관리자, 어두운 계열 버튼 |
| Warning/Danger | `bg-rose-600` / `hover:bg-rose-700` | `#E11D48` / `#BE123C` | 비활성화, 퇴사 처리, 차단 |
| Background | `bg-slate-50` | `#F8FAFC` | 전체 화면 배경 |
| Card Surface | `bg-white` | `#FFFFFF` | 카드 및 팝업 배경, 테두리 `#E2E8F0` |
| Badge: 승인대기 | `bg-amber-100 text-amber-800` | `#FEF3C7` / `#92400E` | `pending` 상태 표기 |
| Badge: 승인(재직) | `bg-emerald-100 text-emerald-800` | `#D1FAE5` / `#065F46` | `approved` 상태 표기 |
| Badge: 퇴사/비활성 | `bg-slate-100 text-slate-600` | `#F1F5F9` / `#475569` | `resigned`, `inactive` 상태 표기 |

#### 컴포넌트 규격
- 카드 모서리: `rounded-2xl` (16px), 테두리 `border border-slate-200`, 그림자 `shadow-sm`
- 버튼 크기: 최소 높이 46px, `rounded-xl` (12px), 폰트 굵기 600
- 입력 필드: 최소 높이 46px, 숫자 비밀번호 입력 시 마스킹(`type="password"`), 한글 오류 메시지 지원
