## 1. 화면과 주소(URL) 구성

### 화면 구성

| URL 경로 | 화면명 | 주요 UI 요소 |
| --- | --- | --- |
| `/` | 메인 / 로그인 화면 | 재직 직원 선택 드롭다운, 4자리 PIN 입력 필드, 로그인 버튼, 회원가입 링크 |
| `/signup` | 직원 회원가입 화면 | 이름 입력, 4자리 PIN 입력, 시급 입력, 가입 신청 완료 버튼 |
| `/admin/setup` | 최초 관리자 등록 화면 | 관리자 이름, PIN 입력, 등록 완료 버튼 (관리자 존재 시 접근 차단) |
| `/employee/dashboard` | 직원 마이페이지 | 출근/퇴근 시간 입력, 근무 내역 리스트, 예상 급여 텍스트 |
| `/admin` | 관리자 대시보드 | 직원별 월별 급여 요약 표, 직원 상태(승인/대기/퇴사) 변경 관리 탭 |
| `/admin/attendance` | 관리자 근무 기록 관리 | 직원별 출근/퇴근 시간 수정/삭제 모달 포함 테이블 |

### 디자인 시스템 색상 (Hex)

## 2. 디자인 가이드

### 디자인 가이드
- **폰트**: Pretendard (산세리프)
- **버튼 스타일**: 모바일 터치 친화적으로 높이 48px 이상, 둥근 모서리(`rounded-lg`)
- **반응형 디자인**: 모바일 웹 최우선 세로형 레이아웃 (`max-w-md mx-auto` 컨테이너 구조)
