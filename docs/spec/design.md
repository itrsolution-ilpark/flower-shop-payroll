## 1. 화면과 주소(URL) 구성

### 화면 구성

| URL 경로 | 화면명 | 주요 UI 요소 |
| --- | --- | --- |
| `/system-setup` | 시스템 관리자 최초 등록 화면 | 시스템 관리자 이름, 4자리 PIN 입력 및 확인용 재입력, 등록 버튼 |
| `/` | 메인 / 플라워샵 검색 및 선택 화면 | 타이틀 "플라워샵 근무 관리", 플라워샵 검색 입력창, 플라워샵 목록 표시, '시스템 관리자 로그인 후 플라워샵 등록' 버튼 |
| `/shop/register` | 플라워샵 등록 및 수정 화면 (시스템 관리자 전용) | 플라워샵명 입력 필드, 등록/수정 완료 버튼 |
| `/shop/[id]` | 플라워샵 허브 화면 | 선택된 플라워샵 이름 표시, 관리자 미등록 시 '관리자 등록' 화면으로 이동 버튼 / 등록 완료 시 '직원 로그인', '직원 가입' 버튼 노출 |
| `/signup` | 직원 회원가입 화면 | 플라워샵 고정, 이름 입력, 4자리 PIN 입력 및 확인용 PIN 재입력, 시급 입력, 가입 신청 버튼 |
| `/admin/setup` | 플라워샵별 관리자 등록 화면 | Title: "플라워샵별 관리자 등록 화면", 샵 고정 표시, 관리자 미등록 시 신규 등록 모드(쿼리 버그 수정 반영), 기등록 시 내역 표시 및 수정 모드 |
| `/employee/dashboard` | 직원 마이페이지 (플라워샵별 직원) | 출근/퇴근 시간 입력, 본인의 월별 근무 현황 및 급여 산정 내역 조회 |
| `/admin` | 관리자 대시보드 (플라워샵 대표용) | 전체 직원의 각 플라워샵별 직원 내역(직원, 근무 시간, 시급, 월별 근무 및 급여) 조회 및 수정 탭 |

### 디자인 시스템 색상 (Hex)
- 주 색상(Primary): `#2E7D32` (포레스트 그린)
- 보조 색상(Secondary): `#81C784` (연두색)
- 배경 색상(Background): `#F1F8E9` (연한 초록빛)
- 텍스트 색상: `#212121` (진한 회색)
- 에러 색상: `#D32F2F` (빨강)

## 2. 디자인 가이드

### 디자인 가이드
- **폰트**: Pretendard (산세리프)
- **버튼 스타일**: 모바일 터치 친화적으로 높이 48px 이상, 둥근 모서리(`rounded-lg`)
- **반응형 디자인**: 모바일 웹 최우선 세로형 레이아웃 (`max-w-md mx-auto` 컨테이너 구조)
