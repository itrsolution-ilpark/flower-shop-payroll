## 1. 화면과 주소(URL) 구성

### 화면 목록 및 UI 상세 레이아웃

| URL 경로 | 화면명 | 핵심 UI 구성요소 및 동작 규칙 |
| --- | --- | --- |
| `/system-setup` | 시스템 관리자 최초 등록 화면 | - 헤더: "플라워샵 근무 관리 - 시스템 마스터 설정"<br>- 입력 필드: 관리자 이름, PIN 번호(4자리 숫자), PIN 번호 확인(4자리 숫자)<br>- 버튼: [시스템 관리자 생성 및 시작]<br>- 시스템 관리자가 이미 존재할 경우 `/`로 리다이렉트 |
| `/` | 메인 플라워샵 검색 및 선택 화면 | - 상단 타이틀: "플라워샵 근무 관리"<br>- 상단 우측/중앙: [시스템 관리자 플라워샵 등록/수정] 버튼 (클릭 시 마스터 PIN 확인 모달 후 이동)<br>- 검색창: 실시간 텍스트 인풋 (`placeholder="플라워샵 이름을 검색하세요..."`)<br>- 플라워샵 카드 목록: 샵 이름, 소속 직원 수, [입장하기] 버튼 |
| `/shop/register` | 플라워샵 등록/수정 화면 (시스템 관리자 전용) | - 헤더: "플라워샵 등록 및 관리"<br>- 신규 플라워샵명 인풋 및 [추가] 버튼<br>- 기등록된 플라워샵 리스트 (매장명 수정 인풋 및 [수정 저장] 버튼) |
| `/shop/[id]` | 플라워샵 허브 화면 | - 상단: 선택된 플라워샵명 표시, 메인 화면으로 돌아가기 링크<br>- 조건부 UI:<br>  1. 대표 미등록 시: 안내 문구 ("등록된 대표 관리자가 없습니다.") + [플라워샵 대표 등록] 버튼<br>  2. 대표 등록 완료 시: [플라워샵 대표 로그인], [직원 로그인], [직원 가입 신청] 버튼 카드 노출 |
| `/admin/setup` | 플라워샵별 관리자 등록 화면 | - 상단 타이틀: "플라워샵별 관리자 등록 화면"<br>- 플라워샵명: 현재 `shop_id` 기반 고정 표시 (수정 불가)<br>- DB 조회: `WHERE shop_id = current_id AND is_admin = true`<br>- 폼: 대표 이름, 4자리 PIN, PIN 확인 (등록 모드 또는 정보 수정 모드) |
| `/admin` | 플라워샵 대표 대시보드 | - 상단: 샵 명칭 및 [근무 기록/급여 정산 탭], [직원 관리 탭]<br>- 직원 관리 탭: 승인 대기자 목록(시급 인풋 + [승인] 버튼), 재직자 목록(시급 수정, [퇴사 처리] 버튼), 퇴사자 목록 |
| `/admin/attendance` | 대표 전용 근무 및 급여 정산 화면 | - 월 선택 셀렉트박스 (예: 2025년 05월)<br>- 직원별 월간 총 근무시간, 총 지급 급여 요약 표<br>- 직원별 일자별 출퇴근 기록 조회 및 수동 수정 모달 |
| `/signup` | 직원 회원가입 화면 | - 소속 플라워샵명 고정 표시<br>- 직원 이름 인풋<br>- 4자리 PIN 인풋 및 PIN 확인 인풋<br>- [가입 신청하기] 버튼 (신청 완료 시 "대표 승인 후 이용 가능합니다" 토스트 후 허브로 이동) |
| `/employee/dashboard` | 직원 마이페이지 (근무 및 급여) | - 상단: 직원 이름, 시급 안내 (예: "시급: 10,000원")<br>- 당일 출퇴근 카드: [출근하기] / [퇴근하기] 원클릭 버튼 및 실시간 상태 표시<br>- 이번 달 근무 요약: 총 근무 시간 (00시간 00분), 총 예상 급여 (원 단위 포맷팅)<br>- 하단: 최근 30일 출퇴근 일자/시간 테이블, [PIN 번호 변경] 모달 |

## 2. 디자인 가이드

### 디자인 가이드
- **폰트**: Pretendard (산세리프)
- **버튼 스타일**: 모바일 터치 친화적으로 높이 48px 이상, 둥근 모서리(`rounded-lg`)
- **반응형 디자인**: 모바일 웹 최우선 세로형 레이아웃 (`max-w-md mx-auto` 컨테이너 구조)
